## Stack

- Static HTML / CSS / vanilla JavaScript
- No build step required
- Netlify-ready

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python3 -m http.server 3000
```

## Deploy to Netlify

1. Push this folder to a Git repository, **or** drag-and-drop the folder in the Netlify UI.
2. Publish directory: root of this project (`.`)
3. No build command needed.

Custom domain and HTTPS are handled by Netlify.

## Project data

All project and personal data lives in `js/data.js`.  
Update projects, capabilities, currently-building cards, or contact details there — the UI re-renders from that single source.
